# Harmonia — Music Recommendation System

A content-based music recommendation system built with Python and scikit-learn. Harmonia uses TF-IDF vectorization and cosine similarity to find songs with similar content.

## About the Project

This project began as a Jupyter Notebook implementing a music recommendation engine. It explores how song metadata and lyrics can be used to identify and recommend similar songs.

The goal is to evolve the original recommendation engine into a full-stack web application with an interactive user interface.

## Features

- Content-based music recommendations
- TF-IDF vectorization for text representation
- Cosine similarity for comparing songs
- Exploratory data analysis and visualizations
- Original recommendation engine implemented in Python

## Technologies Used

- Python
- Jupyter Notebook
- Pandas and NumPy
- scikit-learn
- TF-IDF and cosine similarity
- Matplotlib / Seaborn for visualizations, where applicable

## Getting Started

The original implementation is available in `notebooks/initial_music_recommender.ipynb`.

To explore the project:

1. Clone or download this repository.
2. Install the required Python dependencies in a suitable environment.
3. Obtain the dataset from its documented source.
4. Open the notebook in Jupyter Notebook or JupyterLab.
5. Run the cells in order after configuring the dataset path.

Detailed setup instructions and dataset acquisition information will be added as the project evolves.

## Project Status
